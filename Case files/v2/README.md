## Note: Untested!

These files feature a few changes based on feedback to v1
* Typing angle changed from 3° to 5°
* Engraving and foot depth changed from 0.5mm to 1.0mm
* Wheel weight slots added for **heft**
* Alignment tabs added between top and bottom case

*For those with multicolor printers, there are `xxx_Flush` files which have the "engraving" flush with the rest of the case. This makes for a cleaner print if you want to print the design in a seperate color(s)*
